Required Columns

Each Excel file must include: BDC Name · Normalize Name · Industry · Par Amount ($M) · Cost ($M) · Fair Value ($M). One file can contain all 30+ BDCs — the tool splits by BDC Name.

Workflow

1. Upload quarterly SOI files above. 2. Click Scan Files to detect all unique BDC names. 3. Use the 5 dropdowns to select which funds to compare. 4. Choose the Primary Quarter — overlap is computed from that quarter's data only. 5. Click Analyze Overlaps.

Reading Results

Each row = a company held by ≥2 selected funds in the primary quarter. Red FV/Par% <90% = stressed. Amber 90–100% = watch. Green >100% = premium/PIK. "ALL" badge = held by every selected fund.

Pricing Trend Tab

After running overlap, switch to Pricing Trend — it uses the same fund selections and tracks FV/Par% for overlapping companies across all uploaded quarters. One table per fund, sortable by deterioration.

What this shows

For each selected fund, one table tracks every company that overlaps with ≥1 other selected fund — showing its FV/Par% across all uploaded quarters. Identify marks drifting down, diverging between funds, or consistently stressed.

Overlap universe

The overlap universe here is computed across all uploaded quarters (a company is included if it overlaps in any quarter). This gives a broader view than the single-quarter overlap in Tab 1.

Reading the Δ column

Δ Q1→Latest = change in FV/Par% from the first to the most recent quarter (in percentage points). ↓ negative = deteriorating marks. ↑ positive = improving. Sorted stressed-first by default.

Purpose

Pick any one company and up to 10 BDC funds. The line chart shows how each fund's FV/Par% for that company moves across the uploaded quarters. Great for spotting marking divergence across the market for a single credit.

Company List

The company dropdown is populated from all uploaded quarterly files across all funds — fully independent of Overlap or Trend tabs. Type to search. Companies are de-duplicated by normalised name.

Fund Selection

Select up to 10 funds using the checkboxes. Only funds that hold the selected company (in any quarter) will show a line. Funds with no data for that company are shown as gaps.
